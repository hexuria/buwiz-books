## Full Export (Settings → Export / Import)

**Settings → Export / Import** exports the organization's records as one JSON file (or CSV
sections) and imports them back one kind at a time. Besides the books — chart of accounts,
parties, banks, products, transactions, bills, invoices — the file carries the Inbox's own
configuration:

| Data Type                   | What comes along                                                            |
| --------------------------- | --------------------------------------------------------------------------- |
| **Rule Snapshots**          | Each frozen rule pack, with its label and the exact time it was made        |
| **Routines**                | How papers get in: inbound email, signed webhooks, and schedules, with pins |
| **Classification Memories** | The answers the Inbox remembers, with their use and undo counts, on or off  |

Import them in that order, after vendors, customers, and the chart of accounts:

- **Signing secrets never leave.** A signed webhook routine arrives turned off; generate a new
  secret for it, update the sender, then turn it on.
- A routine that uses a rule snapshot needs that snapshot imported first.
- Your organization keeps a single inbound email routine; an imported one is skipped if you
  already have it.
- A memory whose vendor, customer, or account is not in this organization is skipped and listed
  in the import results, so you can see what was not brought over.

Importing the same file twice adds nothing the second time.

## CSV Format Requirements

### Transactions CSV

```csv
Date,Description,Amount,Category,Party,Department,Location
2026-01-15,Office rent,$2200.00,Rent Expense,WeWork,,Main Office
2026-01-15,Consulting revenue,-$5000.00,Consulting Revenue,Acme Corp,Sales,
```

### Chart of Accounts CSV

```csv
Name,Type,ParentName,Description
Bank Accounts,asset,,Operating cash accounts
Mercury Checking,asset,Bank Accounts,Primary checking account
Accounts Payable,liability,,Vendor obligations
```

## Migration Guide

When migrating from another accounting system:

<Steps>
  <Step title="Export from Old System">
    Export your chart of accounts and transaction history as CSV files.
  </Step>
  <Step title="Import Chart of Accounts">
    Import the CoA first — this creates the account structure before transactions reference them.
  </Step>
  <Step title="Import Transactions">
    Import transactions in chronological order (oldest first).
  </Step>
  <Step title="Import Entities">Import vendors and customers to link to transactions.</Step>
  <Step title="Verify">
    Run a Trial Balance and compare against your old system to ensure everything migrated correctly.
  </Step>
</Steps>
