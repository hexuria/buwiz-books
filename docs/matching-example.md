Example Scenario: Matching Two Transactions
Suppose you want to match a deposit from your bank feed with a manually entered Pay In transaction for the same amount.

Step 1: Create the First Transaction (Pay In)
Go to Accounting → Ledger.
Click + Add Transaction > Pay In.
Enter the details—make sure to note the amount (e.g., $500.00), date, party, and category.
Save the transaction.
Step 2: Create the Second Transaction (e.g., Bank Feed)
If you already have a bank connection, you might see an imported transaction for the same $500.00 deposit. If not, you can create a second manual Pay In for the same amount, but with a different description or party.
Step 3: Match the Transactions
In Accounting → Ledger, click the Edit icon to enter edit mode.
Find both $500.00 transactions (use filters if needed).
Check the boxes next to both transactions.
Click the Match icon that appears at the top.
Confirm when prompted.
Tip: The amounts must be identical to match. Other fields (like date, party, or category) help guide matching but are not required to be the same.

This is a great way to practice how Buwiz Books merges duplicate or related entries for a clean, audit-ready record.
