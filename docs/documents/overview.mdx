## Overview

The **Documents** module provides centralized storage for all your financial documents — receipts, invoices, contracts, statements, and more.

## Document Types

| Type           | Examples                                |
| -------------- | --------------------------------------- |
| **Receipts**   | Purchase receipts, expense reports      |
| **Invoices**   | Vendor bills, customer invoices         |
| **Statements** | Bank statements, credit card statements |
| **Contracts**  | Service agreements, leases              |
| **Tax Forms**  | W-9s, 1099s, tax returns                |
| **Other**      | Any supporting financial document       |

## Document List

The documents page shows all uploaded files with:

- **Name** — File name or AI-extracted title
- **Type** — Document classification
- **Date** — Upload date or document date
- **Status** — Processing status (classifying, ready, linked)
- **Linked Transaction** — Associated ledger entry, if any
