## Export Options

Buwiz Books provides several ways to export your financial data:

### Transaction CSV Export

Export the currently filtered transaction list as a CSV file:

1. In the Ledger, set your desired date range and filters
2. Click the **⋯ menu** → **Export CSV**
3. The file downloads immediately with all visible transactions

The exported CSV includes:

- Date, Description, Party
- Account (Category)
- Debit and Credit amounts
- Department and Location tags
- Transaction status

### Financial Package (ZIP)

For a comprehensive export, use the **Download Financial Package** feature to generate a ZIP archive containing multiple reports. See [Financial Package](/ledger/financial-package) for details.

## Report Exports

Individual financial reports can also be exported:

- **Trial Balance** → XLSX
- **Profit & Loss** → XLSX
- **Balance Sheet** → XLSX
- **Cash Flow Statement** → XLSX

These are generated as part of the Financial Package or can be exported individually from the Financials page.

## Data Formats

| Export               | Format | Contents                                   |
| -------------------- | ------ | ------------------------------------------ |
| **Transaction List** | CSV    | Raw transaction data with all fields       |
| **Trial Balance**    | XLSX   | Account balances with debits/credits       |
| **Profit & Loss**    | XLSX   | Revenue and expense summary                |
| **Balance Sheet**    | XLSX   | Assets, liabilities, equity snapshot       |
| **Cash Flow**        | XLSX   | Operating, investing, financing activities |

<Tip>
  Exported XLSX files are formatted with headers, number formatting, and ready for review by your
  accountant or auditor.
</Tip>
