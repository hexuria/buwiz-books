## What is the Ledger?

The **Ledger** is the central transaction register in Buwiz Books. Every financial event — purchases, sales, payments, transfers, and adjustments — is recorded here as a double-entry journal entry.

## Ledger Layout

The ledger is divided into these sections:

### Header Bar

- **Smart Date Filter** — AI-powered date range picker with presets and natural language input ([learn more](/ledger/viewing-transactions))
- **View / Edit Toggle** — Switch between read-only and inline editing modes
- **+ Add Transaction** — [Create a new journal entry](/ledger/creating-transactions)
- **⋯ Menu** — Access import, export, and [financial package download](/ledger/financial-package) options

### Account Sidebar (Left)

A hierarchical tree of your Chart of Accounts showing:

- Account name and number
- Transaction count per account
- Accounts grouped under **Assets**, **Liabilities**, and **Equity** roots
- Click any account to filter the ledger to that account's transactions

### Transaction List (Center)

Transactions grouped by account, showing:

- **Date** — When the transaction was posted
- **Party** — The vendor, customer, or entity involved (with colored avatar)
- **Source** — Whether the transaction was manual (M) or bank-imported
- **Category** — Which account the entry is under
- **Department / Location** — Dimensional tags, if assigned
- **Debit / Credit** — The entry amount, color-coded
- **Balance** — Running balance for the account

### View Modes

| Mode          | Icon | Description                                               |
| ------------- | ---- | --------------------------------------------------------- |
| **Grouped**   | ☰   | Transactions grouped under account headers with subtotals |
| **Flat List** | ≡    | All transactions in a single chronological list           |
| **Compact**   | ▤    | Compressed view for scanning large datasets               |
