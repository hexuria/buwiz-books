## Overview

**Locations** let you tag transactions by physical business location — useful for multi-location businesses, retail chains, or companies with regional operations.

<img src="/images/dimensions/locations.png" alt="Locations" />

## Managing Locations

### Creating a Location

1. Navigate to **Locations** in the Accounting section
2. Click **+ New Location**
3. Enter the location name (e.g., "Main Office", "Warehouse", "Downtown Store")
4. Add address and other details

### Location List

The Locations page shows all locations with:

- **Location Name**
- **Address**
- **Transaction Count**
- **Total Amount**

## Tagging Transactions

Select a **Location** when creating or editing transactions. This enables:

- **Location-based reporting** — See P&L by location
- **Regional analysis** — Compare performance across branches
- **Lease and facility cost tracking** — Allocate costs to specific locations

## Combining Dimensions

Departments and Locations can be used together on the same transaction:

| Transaction                | Department | Location       |
| -------------------------- | ---------- | -------------- |
| Office rent payment        | Operations | Main Office    |
| Marketing campaign expense | Marketing  | Downtown Store |
| Sales team payroll         | Sales      | Main Office    |

This two-dimensional tagging enables powerful cross-cutting analysis.
